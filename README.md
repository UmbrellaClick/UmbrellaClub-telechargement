# UmbrellaClub — تحميل البرنامج

برنامج تسيير النوادي الرياضية: القاعات، الرياضيون، الحصص، الحضور بالباركود، المدفوعات، الأحزمة والاختبارات.

## التحميل

- **برنامج التثبيت (آخر نسخة):** [UmbrellaClub-Setup.exe](https://github.com/UmbrellaClick/UmbrellaClub-telechargement/releases/latest/download/UmbrellaClub-Setup.exe)
- **دليل الاستخدام (PDF):** [Guide-UmbrellaClub-AR.pdf](https://github.com/UmbrellaClick/UmbrellaClub-telechargement/releases/latest/download/Guide-UmbrellaClub-AR.pdf)

كل النسخ السابقة في صفحة [الإصدارات](https://github.com/UmbrellaClick/UmbrellaClub-telechargement/releases).

## التثبيت

1. شغّل `UmbrellaClub-Setup.exe`.
2. إن ظهرت رسالة **"Windows a protégé votre ordinateur"**، اضغط **Informations complémentaires** ثم **Exécuter quand même**.
3. للتحديث: شغّل ملف التثبيت الجديد فوق القديم، وتبقى كل بيانات ناديك.

يمكن استعمال برنامج تنزيل (IDM، Neat Download Manager…)، ويمكن استئناف التحميل إن انقطع.

لأي سؤال: قسم **المساعدة** داخل البرنامج.
